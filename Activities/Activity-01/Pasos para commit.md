# pasos para hacer commit en su github

Asegurarse que estan en la carpeta a respaldar en github

- git init
- git add .
- git branch -M main
- git remote add origin <su link de github que termina en .git> ejemplo: https://github.com/ernestolar/A_algo.git
- git config user
- git commit -m "primer commit"
- git push ---set-upstream origin main

# Para futuros cambios solo:

- git add .
- git commit -m "su mensaje de cambio"
